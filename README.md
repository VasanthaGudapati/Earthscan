EarthScan: Deep Learning for Satellite Image Analysis is a major project developed by final-year Information Technology students aimed at leveraging advanced deep learning techniques for classifying high-resolution satellite images. The project focuses on a comparative analysis of models such as VGG16 and MobileNetV2 using the EuroSAT dataset, which includes diverse land cover classes like forests, urban areas, water bodies, and agricultural land. By implementing data preprocessing, augmentation, and transfer learning with pre-trained models, the project evaluates performance based on accuracy and efficiency. It identifies the most effective deep learning approach for land cover classification, contributing to the broader field of remote sensing and geospatial analysis. Through rigorous experimentation and model evaluation, this project not only enhances understanding of satellite image processing but also demonstrates the practical capabilities of AI in environmental monitoring and planning.
